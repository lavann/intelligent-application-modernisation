## This publication

The dedicated **Intelligent Application Modernisation** repository was prepared on **10 November 2026**. It adds an agent-focused front page, usage and team-adoption guidance, a worked-example index, citation metadata, an attribution notice and a fresh validation record.

The five original agent files, five skill files, original worked outputs, application source and tests are preserved without content changes. The original root README is retained at [guides/original-source-readme.md](guides/original-source-readme.md) for reference; use the new worked-example guide for corrected setup context. Original MIT and third-party copyright notices remain in place. New publication guidance is attributed to Lavan Nallainathan.

The [source manifest](provenance/source-manifest.json) records the original commit, source and destination paths, Git blob IDs and SHA-256 hashes for the source files. It makes the extraction independently checkable. Packaging additions are identified separately by the new commits.

January 2026 describes the origin of the source pack. November 2026 describes this dedicated publication. Dates embedded in generated reports and the inherited 2025 copyright notice should not be substituted for those Git records. The history also includes AI-assisted contributions recorded under their original bot author identities.
